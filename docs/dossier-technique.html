1. Synthèse Exécutive & Métriques Clés

Ce projet de refonte a été mené avec une ambition claire : aligner la qualité de la vitrine numérique de Kreativ'Pulse avec l'excellence de son savoir-faire créatif et événementiel. L'ancien site sous WordPress (thème Bridge / WPBakery), bien qu'ayant servi de point d'ancrage historique, souffrait de lenteurs structurelles, d'un taux de rebond élevé sur smartphone et d'une incapacité à valoriser efficacement l'offre de goodies et de signalétique.

En repartant d'une feuille blanche avec les standards web les plus modernes (Jamstack, CSS modulaire accéléré matériellement, base de données PostgreSQL temps réel), les gains obtenus sont factuels et sans appel :

2. Architecture Technique Découplée (Jamstack)

Contrairement à une pile WordPress monolithique où le serveur PHP doit reconstituer chaque page à chaque requête SQL, nous avons opté pour une architecture Jamstack découplée :

┌────────────────────────────────────────────────────────────────────────┐ │ FRONTEND JAMSTACK ULTRA-RAPIDE │ │ HTML5 Sémantique + Vanilla CSS Modularisé + Vanilla JS ES6+ │ │ (Distribué à la périphérie mondiale sur le CDN Vercel Edge) │ └───────────────────▲────────────────────────────────▲───────────────────┘ │ │ │ PostgREST API (REST) │ Canvas HTML5 │ Zéro bundle tiers │ Compression Client-Side ┌───────────────────▼────────────────────┐ ┌────────▼───────────────────┐ │ SUPABASE POSTGRESQL (CLOUD) │ │ MÉDIAS OPTIMISÉS │ │ - Table kp_leads (Devis & Briefs) │ │ - Formats WebP / AVIF │ │ - Table kp_projects (Portfolio) │ │ - Cache local transparent │ │ - Double persistance avec localStorage │ │ - Ratios natifs respectés │ └────────────────────────────────────────┘ └────────────────────────────┘

Pourquoi ce choix est déterminant pour l'entreprise :

  • Temps de chargement divisé par 7 : Le poids moyen par page est passé de 8.4 Mo sur WordPress à seulement ~1.2 Mo, offrant une réactivité immédiate même avec une connexion 3G/4G limitée.
  • Vulnérabilités éliminées : Aucun fichier PHP exposé, aucun plugin tiers vulnérable, aucune injection SQL possible.
  • Coût d'hébergement nul : Le site est servi gratuitement et mondialement via Vercel Edge avec certificat SSL Let's Encrypt auto-renouvelé.
  • Double persistance résiliente : Toutes les interactions (panier de devis, briefs soumis, projets) sont stockées dans PostgreSQL Supabase tout en restant sauvegardées localement en secours (`localStorage`).

3. Design System & Identité Visuelle Premium

En tant que stagiaire en graphisme, j'ai apporté un soin méticuleux à la charte graphique afin de transmettre le prestige d'une agence haut de gamme :

  • Thématique Sombre Cinématographique : Fond noir profond (`#08090C`) et surfaces glassmorphism (`rgba(255,255,255,0.03)` à `0.05` avec `backdrop-filter: blur(16px)`).
  • Orange Signature Kreativ'Pulse : Teinte `#FF7500` rehaussée par des halos néon diffus (`rgba(255,117,0,0.35)`), évoquant le dynamisme et le « pouls » de l'agence.
  • Typographies Modernes : `Outfit` pour les titres géométriques à fort impact visuel, combiné à `Inter` / `Plus Jakarta Sans` pour un confort de lecture optimal.
  • Micro-animations subtiles :
    • Hero 3D en arc : Carrousel cylindrique avec perspective CSS immersive.
    • Menu burger mobile en cascade (Stagger effect) : Déroulé fluide inspiré des applications iOS natives avec décalage progressif des rubriques (50ms, 90ms, 130ms...) au lieu d'un pop-up brutal.
    • Lightbox multi-images proportionnée : Commandes vectorielles SVG pures centrées au pixel près, rapport 1:2 harmonieux, commandes au doigt (swipe tactile) et fond d'ambiance dynamique flouté.
  • Règle éditoriale stricte : 100% Français, aucun anglicisme parasite, coordonnées réelles et officielles de l'agence (`Sicap Liberté 5/C, Dakar`).

4. Nouveautés Métier & Conversion Commerciale

A. Catalogue & Boutique Mandarine SN (+200 Références)

Pour valoriser l'activité de régie publicitaire, un catalogue e-commerce interactif sans dépendance externe a été intégré :

  • 4 Univers Marchandises : Objets publicitaires, Décoration numérique, Salons & événements, Présentoirs LED & affichage grand format.
  • Moteur de Recherche Instantané : Recherche avec temporisation (`debounce 250ms`) et filtres par sous-catégories.
  • Fiche Produit Interactive : Modale avec zoom HD, caractéristiques de marquage (sérigraphie, broderie, gravure laser) et sélecteur de quantité.
  • Panier de Devis WhatsApp en 1 Clic : Génération automatique d'un message pré-rempli transmis directement sur l'application WhatsApp de l'agence pour signer les contrats sans friction.

B. Espace de Gestion Autonome — Pulse Studio Manager (`admin.html`)

Pour que l'équipe puisse piloter le contenu sans solliciter constamment un développeur :

  • Accès sécurisé par code PIN : Personnalisable en direct avec sauvegarde chiffrée.
  • CRUD Portfolio avec Compresseur Canvas : Importation directe de photos de projets (JPG, PNG, WebP) redimensionnées automatiquement côté client sans saturer le serveur ni la base.
  • Boîte de réception des leads en temps réel : Réception directe des briefs et demandes de devis avec lien rapide pour rappeler le prospect sur WhatsApp.
  • Sauvegarde JSON en 1 Clic : Export complet de la base de données pour archivage.
